
# AI Productivity Assistant

A modern productivity assistant built to streamline daily workflows and tasks.

## Features
- AI-powered task management and automation
- Clean, responsive UI built with Tailwind CSS and TypeScript
- Fast development workflow with Vite

## Tech Stack
- **Framework / Bundler:** Vite, React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
